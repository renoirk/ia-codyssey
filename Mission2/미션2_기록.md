- 좁히려고 해 본 것과 결과:
  > 공백이 있는 영화 제목과 없는 제목을 이동하며 비교. 새로운 영화이름도 추가해서 같은 작업 실행
  > 
- AI가 말한 원인과, 그 설명을 직접 확인한 결과:
   > 영화 제목에 공백이 있으면 카드의 식별값(ID)이 잘못 저장되는 것이 원인입니다.
    >기존 HTML 코드에는 다음과 같은 부분이 있었습니다.
   
      data-id=' + item.id + '

  >영화 제목을 HTML 속성값에 넣으면서 따옴표로 감싸지 않았습니다. 예를 들어, "센과 치히로" 영화 제목은 "센과" 라는 ID로 저장되어 드래그할 때 전달되는 값(센과)이 실제 영화 검색 결과(센과 치히로)와 일치하는 영화가 없다고 나옵니다.

  > 확인한 내용: Chrome 개발자 도구의 Elements 탭을 이용하여, 수정 전 HTML 파일을 열어, 영화 카드에서 마우스 오른쪽 버튼을 클릭 후 검사(Inspect) 를 선택하여 개발자 도구의 요소 탭에서 해당 영화의 <button> 코드를 확인했다. AI 설명대로 제목과 ID가(센과) 다름.

## 민수 님께 보낼 피드백

### 잘된 점: [직접 써 보니 좋았던 것]

1. S·A·B·C 등급 칸이 위에 있고, 미분류 영화 카드가 아래에 배치되어 있어 전체 구성을 한눈에 파악하기 쉬웠다.
2. 영화 카드를 누른 뒤 등급을 선택하거나, 드래그 앤 드롭으로 옮기는 기능이 모두 정상적으로 작동했다.
3. 영화 제목을 입력하고 추가 버튼을 누르면 새로운 영화 카드가 정상적으로 생성되었다.
4. 처음으로 버튼을 누르면 최초 영화 8개가 모두 미분류 상태로 돌아갔다.
5. 영화를 등급별로 분류한 후에도 각 영화가 한 칸에만 남아 있어 중복 분류 문제가 없었다..
6. 등급마다 색상이 달라 S·A·B·C 칸을 구분하기 쉬웠다.
7. '8편 중 3편 나눔'처럼 전체 영화 수와 분류한 영화 수를 보여 주어 진행 상황을 파악하기 좋았다.
8. 외부 파일이나 로그인 없이 HTML 파일 하나만으로 실행할 수 있었다.

### 고치면 좋을 점
   본 것: [한 행동]을 했더니 [실제 결과]가 나왔다
   기준: 기획서의 [조건] (기획서에 없다면 쓰다가 불편했던 점)
   제안: [이렇게 바뀌면 좋겠다]

1. 영화 카드의 정렬 순서가 예상과 다르게 나타남
    - 본 것: 기생충과 인터스텔라 카드를 차례대로 선택해 같은 등급 칸으로 옮겼더니, 선택한 순서와 관계없이 해당 칸의 맨 앞에 위치했다.
    - 기준: 기획서의 영화가 한 칸에만 있고 옮긴 칸에 남는다는 조건은 충족하지만, 카드의 정렬 순서는 별도로 정의되어 있지 않다.
    - 제안: 나중에 옮긴 영화는 해당 칸의 마지막에 추가되도록 하거나, 사용자가 원하는 순서대로 카드를 배치할 수 있도록 개선하면 좋겠다.
2. 브라우저를 다시 열면 분류 결과가 사라짐
    - 본 것: 영화를 등급별로 분류하고 HTML 파일을 닫았다가 같은 브라우저에서 다시 열었더니 초기 상태로 리셋되었다.
    - 기준: 기획서의 '같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남는다'는 조건을 충족하지 못한다.
    - 제안: 브라우저의 localStorage를 활용해 영화 목록과 등급 정보를 자동 저장하고, 다시 열었을 때 마지막 작업 상태가 복원되도록 개선하면 좋겠다.
3. 화면 폭이 좁아지면 오른쪽 내용이 잘림
    - 본 것: 화면 폭을 좁히거나 휴대폰에서 열었더니 오른쪽 내용이 잘려 보이지 않았고, 한 화면에 내용을 맞추려면 글씨가 너무 작아졌다.
    - 기준: 기획서의 '화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있다'는 조건을 충족하지 못한다.
    - 제안: PC, 태블릿, 휴대폰 화면 크기에 따라 자동으로 레이아웃과 카드 크기가 조정되는 반응형 화면으로 개선하면 좋겠다.
4. 드래그 앤 드롭 시 안내 색상 변화가 잘 보이지 않음
    - 본 것: 영화를 드래그해서 등급 칸으로 옮기려고 했지만, 놓을 위치의 배경색이 바뀌는 것을 확인하기 어려웠다.
    - 기준: 기획서에는 드래그 앤 드롭 기능이 명시되어 있지만, 드래그 중 위치를 시각적으로 안내하는 조건은 별도로 없다.
    - 제안: 드래그 중 마우스가 위치한 등급 칸의 배경색이나 테두리를 더 명확하게 변경해 놓을 위치를 쉽게 알 수 있도록 하면 좋겠다.
5. 카드 이동 방법에 대한 설명이 부족함
    - 본 것: 처음 사용할 때 카드를 선택한 다음 등급 글자를 눌러야 하는지, 카드를 직접 끌어야 하는지 사용 방법을 바로 이해하기 어려웠다.
    - 기준: 기획서에는 카드 선택 및 드래그 앤 드롭 기능이 있지만, 사용 방법에 대한 안내는 없다.
    - 제안: 화면 상단에 '카드를 선택한 후 S·A·B·C를 누르거나, 원하는 칸으로 끌어 놓으세요'라는 간단한 사용 안내를 추가하면 좋겠다.
6. 영화 포스터 이미지가 없어 시각적인 재미가 부족함
    - 본 것: 영화 제목만 카드에 표시되어 있어 영화별 특징을 직관적으로 파악하기 어려웠다.
    - 기준: 기획서에는 영화 제목을 카드로 표시하는 기능만 요구하고 있으며, 포스터 이미지는 필수 조건이 아니다. 사용하면서 발견한 개선 아이디어다.
    - 제안: 각 영화 카드에 영화 포스터 이미지를 함께 표시하면 시각적으로 더 풍부하고 재미있는 티어리스트가 될 것 같다.
7. 미분류 영화 목록의 위치 개선 검토
    - 본 것: 미분류 영화가 화면 아래쪽에 있어 S등급 칸으로 드래그하려면 카드를 끌면서 화면을 위로 스크롤해야 했다.
    - 기준: 기획서에는 미분류 영화가 아래에 배치된다고 명시되어 있으므로 현재 구현은 기획서에 부합한다. 다만 실제 사용 과정에서 불편함을 발견했다.
    - 제안: 미분류 영화 목록을 화면 위쪽이나 옆쪽에 배치하는 방안을 검토하면 좋겠다. 또는 카드 선택 후 등급 버튼을 누르는 방식을 활용하도록 안내하면 드래그 없이도 편리하게 사용할 수 있다.

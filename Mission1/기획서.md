# 영화 티어리스트 웹페이지 기획서

## 1. 누가 쓰나 (Target User)
* 본인이 직접 감상한 영화를 정리하고 기록하는 개인 사용자

## 2. 무엇을 하려고 (Purpose)
* 나만의 영화 취향을 시각적으로 아카이빙하고 공유하기 위함
* 마우스(또는 터치) 드래그 앤 드롭을 이용해 직관적으로 티어를 나누는 재미 요소 제공

## 3. 화면과 동작 (UI & Interaction)
* **티어 판 구성:** 
  * S, A, B, C, D 등급별로 가로 줄(Row)을 위에서부터 아래로 배치
  * 각 등급을 구분하기 쉽도록 줄마다 다른 테마 색상 부여 (예: S는 빨간색 등 강렬한 색, D는 파란색 계열 등)
* **영화 카드 추가 동작:** 
  * **방식 1:** 미리 제공되는 하단의 '기본 영화 목록'에서 원하는 썸네일을 윗단 티어 판으로 끌어다 놓기
  * **방식 2:** 사용자가 직접 영화 제목을 입력하고 포스터 이미지(링크 또는 파일 업로드)를 등록하여 나만의 카드 생성 후 끌어다 놓기

## 4. 필요한 자료 (Data & Features)
* **데이터 영구 보관:** 브라우저 저장소(Local Storage 등)를 활용하여 창을 닫거나 새로고침해도 사용자가 배치한 티어리스트 내역이 그대로 유지되는 기능
* **저장 및 공유 기능:** 완성된 최종 티어리스트 화면을 깔끔한 이미지 파일(PNG/JPG)로 다운로드하고, 다른 곳에 링크 등으로 공유할 수 있는 기능

## 5. 완성 기준 (Definition of Done)
* 화면 디자인이 깔끔하게 구성되어야 함
* PC뿐만 아니라 모바일 환경에서도 드래그 앤 드롭이 부드럽게 잘 작동해야 함
* 영화 포스터를 자유롭게 추가하고, S~D 티어에 성공적으로 배치할 수 있어야 함
* 배치 완료 후, 번거로운 화면 캡처 없이 버튼 클릭만으로 결과물이 이미지로 완벽하게 저장되어야 함

---

### 💡 아직 정하지 않은 사항 (추후 결정 필요)
지금까지 나눈 대화에서 아직 구체적으로 정해지지 않은 부분들입니다. 이 부분들은 개발을 진행하면서 차차 정해도 괜찮습니다.

1. **기본 제공 영화 목록:** 사용자가 접속했을 때 화면 하단에 미리 깔려있을 '기본 영화 카드'들은 어떤 작품들로 채울지 미정입니다. (예: 역대 흥행작 20선, 최근 개봉작 등)
2. **구체적인 디자인 및 색상 테마:** S~D 각 티어의 정확한 색상 코드나, 웹페이지 전체의 배경색(다크 모드 혹은 라이트 모드)은 아직 정하지 않았습니다.
3. **링크 공유의 기술적 구현:** 이미지 다운로드는 프론트엔드 단에서 쉽게 처리가 가능하나, 고유 '링크(URL)'를 통한 공유가 필요할 경우 서버(데이터베이스) 구축 여부를 결정해야 합니다.
